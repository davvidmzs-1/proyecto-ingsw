# Sistema de Gestión de Reservas y Ocupación para Motel

Trabajo Práctico Integrador — Ingeniería de Software I, UniNorte.

Sistema para gestionar la disponibilidad, reserva y ocupación de las habitaciones del **Motel Piel con Piel**, permitiendo tanto reservas anticipadas como check-in inmediato (walk-in), con cálculo automático del cobro según el tiempo de estadía.
